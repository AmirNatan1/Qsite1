# Phase 5A-R supporting-route identity repair lab

`QH_PHASE5AR_ROUTE_LAB_ONLY`

This directory is a local-only preproduction lab for the Phase 5A-R anti-template repair. It is parallel to the accepted Phase 5A lab and is not an Astro production input. Nothing here replaces a public supporting route, changes approved publication copy, or authorizes Phase 5B.

The repair keeps the accepted route propositions while changing their document architecture:

- For industry — four-act continuous pressure system;
- For startups — four-act directional alignment corridor;
- Industries — concise prelude, four territory acts, concise coda;
- Proof — two-act archive threshold and one record;
- Maradin — six-act documentary record;
- SPARK — three-act runway, sealed gate, contextual release;
- About — three-act institutional interlock;
- Contact — one principal three-rail arrival field;
- 404 — one compact misregistered recovery field.

Run locally:

```text
node prototypes/phase-5a-r-supporting-routes/server.mjs --port=4176
```

The loopback server exposes only the nine route studies, `/system/`, local CSS/JavaScript, self-hosted fonts, and the three governed Maradin stills. Every response is `noindex, nofollow`, carries the lab canary, rejects state-changing methods, and uses a deny-by-default content security policy.

Boards:

- `?board=page` — route-specific semantic document;
- `?board=signature` — four to six route-specific behavior states;
- `?board=materials` — decisive route material board.

The JavaScript enhancement is optional. It records local section progress only for routes that declare motion mode B or C. The complete document, navigation, copy hierarchy, media fallbacks, and recovery paths remain available without JavaScript and under reduced motion.

Generated screenshots, sheets, reports, manifests, recordings, and ZIP files must be written to a fresh external directory and must remain untracked.
