# Phase 5A supporting-route preproduction lab

`QH_PHASE5A_ROUTE_LAB_ONLY`

This authored HTML/CSS lab is the compact source for human-review storyboards. It is not part of the Astro application, is not copied to `public/` or `dist/`, has no public deployment path, and contains no Phase 4 cinematic media or runway.

Run locally:

```text
node prototypes/phase-5a-supporting-routes/server.mjs --port=4175
```

The server exposes only the nine approved route studies at their familiar path shapes plus `/system/`, local CSS/JavaScript, self-hosted fonts, and the already-governed Maradin stills. Every response carries `noindex, nofollow`, a deny-by-default content security policy, and the local-lab canary header.

The semantic document is complete without JavaScript. The optional enhancement sets one scroll-progress variable at most once per animation frame and marks observed chapters; it adds no scroll lock, sticky chapter, autoplay, loop, external request, or dependency.

Generated screenshots, contact sheets, route briefs, reports, and the final ZIP must be written to a fresh explicit directory outside the repository. They are never tracked.

Boards:

- `?board=page` — complete route storyboard
- `?board=motion` — signature motion key states
- `?board=materials` — material/detail board
- `?board=type` — typography hierarchy
- `?board=transition` — representative route-to-route transition states

The prototype is deliberately speculative. It does not authorize Phase 5B implementation, new public copy, a contact endpoint, additional public records, or any media publication.
