# Phase 0 original Quantum creative evidence

All files in this directory are original browser-native Phase 0 studies created for Quantum‑Hub. They contain no third-party reference imagery, stock models, photographs, or copied product assets.

## Creative decision

The recommended geometry is a **2.5-turn Archimedean spiral**. Compared with 2.25 turns, it gives conduction enough travel to carry the changing-angle camera beat. Compared with 2.75 turns, it retains clearer turn spacing and lets the Field Unit remain dominant at shorter desktop heights. Its outer terminus enters the right visual perimeter while its inner terminus lands on the unit’s left-side connector, preserving the hero-copy safe area on the left.

Mobile uses a separate 2.25-turn composition. It begins at the lower edge, uses a larger Field Unit, and reduces the apparent camera change.
