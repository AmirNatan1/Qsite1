## Cable review derivative

The raw dedicated cable-camera render remains in `../renders/materials/material-cable.png`. It did not communicate the construction well enough as a review panel. The cable panel in `field-unit-material-sheet.png` is therefore a tight, labeled crop from the actual canonical `../renders/conduction/conduction-70.png` render at source coordinates `[1370, 1060, 1915, 1195]`.

That crop enlarges only existing pixels so the graphite sheath, recessed warm core, one advancing front and contact with the ground can be inspected. It does not repaint or replace the Blender material. The derivative lineage is machine-readable in `../manifests/review-bundle-manifest.json`.

## Portal comparison interpretation

`portal-100.png` is the final physical-glass frame. `first-dom-reference.png` is a separately rendered crisp operating-surface reference using the same authored structural anchors. The overlay compares aperture ownership, crop, navigation-safe zone, heading anchor, route row and audience choices. It is evidence of intended transition continuity, not a claim that glare, glass and semantic DOM pixels should be identical.
