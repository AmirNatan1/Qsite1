## Scope boundary

`accepted F1–F500 physical opening → digital-black breathing beat → browser-native Signal Field → manifesto → Field Map threshold`

## Technology decision

The Signal Field uses semantic DOM, SVG and CSS. No canvas, shader, Three.js,
React, physics system, animation library or new runtime dependency is needed.
Essential text and links remain ordinary DOM content. This is the least-complex
technology evaluated in the brief's required order, so later options were not
justified.

The visual substrate consists of:

- the exact authoritative white Q as the causal source;
- SVG paths for structural pressure, routing and one magenta live signal;
- CSS material layers for restrained directional grain and local interference;
- DOM manifesto words kept whole and continuously understandable;
- ordinary links for the two first trajectories and the complete Field Map.

## State and control flow

Native document scroll remains the only positional authority.

1. Input, resize, restoration or media state marks the physical controller dirty.
2. At most one animation frame reads the latest document position and writes the current state.
3. The frame request clears immediately; no perpetual RAF or interval exists.
4. F1–F500 continues to address only the paused physical decoder.
5. Coordinates 500–512 hold F500 while browser-owned black breathes.
6. Coordinate 513 arms the semantic field.
7. One autonomous, reversible DOM/CSS transition resolves the manifesto without changing scroll position.
8. Reverse scroll clears that field before physical imagery regains authority.
9. The Field Map threshold releases only when its ordinary document position is reached.

The pointer probe is independent of scroll. It is installed only for a fine
hover pointer, batches movement into one RAF, settles to the centre on leave or
cancel, performs no work while stationary, and tears down on a non-persisted
departure or a reduced-motion preference change.

## Navigation and history

The Field Map is a native `details` disclosure containing a labelled `nav` and
eight ordinary links. It works without JavaScript. Enhancement adds Escape,
focus return, a bounded focus loop and a visual recession of the current field.
The Home/brand destination remains `/#entry`; fresh `/` remains the true F1 top.
No controller calls `scroll`, `scrollTo`, `scrollIntoView` or writes `scrollTop`.

## Fallback architecture

- Reduced motion bypasses the cinematic request, preserves the dormant poster,
  shows a resolved static Signal Field/manifesto and exposes direct navigation.
- No JavaScript leaves a compact poster, complete manifesto and ordinary Field
  Map links; the enhanced multi-viewport runway is never activated.
- Touch-only input receives the authored resolved field and no pointer probe.
- A blocked or slow physical asset uses the established bounded watchdog and
  fail-open geometry; no retry loop is introduced.
- A blocked display font falls through to narrow system sans faces without
  hiding or splitting content.
