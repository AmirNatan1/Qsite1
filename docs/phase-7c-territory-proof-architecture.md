## Persistent visual tree and territorial inheritance

The capable desktop/tablet visual is one wide, capped virtual SVG rail inside
one bounded sticky viewport. The normal-flow handoff precedes that runway and
the normal-flow Proof section follows it. The rail contains all abstract
territories from first render. Scroll changes its projection; it never swaps
illustrations, appends nodes, loads a scene or changes the DOM tree.

The carrier is literally one unbroken SVG path:

1. **DECIDE release:** a centred precise line exits the locked Workpiece.
2. **Automotive & Mobility:** the line lowers and stretches into a long lateral
   horizon. Elongated planes enter from side boundaries. There is no vehicle,
   road, metric or autonomous-driving representation.
3. **Logistics & Supply Chain:** the same horizon bends through permanent
   transfer thresholds, briefly separates into neutral support lanes and
   reconnects. The carrier itself does not split into a replacement path.
4. **Industry 4.0 / Advanced Manufacturing:** the transfer thresholds contract
   into nested tooling frames. The carrier passes through one exact tolerance
   axis while earlier routing remains as restrained residue.
5. **Energy & Infrastructure:** the calibration axis enlarges into a supported
   span and vertical conduit. Scale, spacing and structural weight increase;
   no facility, utility metric or generation technology is represented.
6. **Registration:** the conduit narrows into a time/registration line, trace
   noise falls away and fixed planes behave as a film gate.
7. **Proof:** abstract geometry yields to one real documentary image and one
   record. It does not become a grid, archive or case-study carousel.

Permanent neutral groups carry trace memory between territories. Their opacity
may recede but never resets to a new background. The material system stays
carbon-black, graphite, smoked grey, white typography, restrained burgundy,
directional grain and rare magenta. Territory identity comes from axis, scale,
density, pressure, routing, tolerance and load—not a new palette.

The rail width is `clamp(90rem, 500vw, 360rem)`. Its actual travel is measured
as `max(0, trackWidth - viewportWidth)` during the controller read phase. The
write phase applies the projected normalized track position as a pixel
translation. This prevents a fixed `vw` translation from overshooting once the
rail reaches its maximum width. Only the sticky visual clips the rail;
ancestors must not introduce `overflow-y: auto|scroll`, scroll containment or a
nested scroller.

No scroll-addressed property has a CSS transition or animation. There is no
permanent `will-change` allocation on the full rail. Vector paths use
non-scaling strokes where required.

## Exact normalized state model

`projectTerritoryProgress(input)` clamps any numeric input to `[0, 1]`, rounds
public numeric output consistently, and returns an immutable-by-convention
plain object. Invalid numeric input projects to `0`. Calling the function twice
with the same input returns deeply equal values. No prior state, direction,
time, viewport event or velocity participates.

The exact macro-state boundaries are:

| Range | `data-territory-state` | Governing visual meaning |
| ---: | --- | --- |
| `0.00–0.10` | `release` | DECIDE pressure releases; carrier remains centred; normal-flow handoff. |
| `0.10–0.28` | `automotive` | Long low lateral opening and controlled horizon. |
| `0.28–0.36` | `automotive-logistics` | Horizon folds into transfer rails without a scene reset. |
| `0.36–0.50` | `logistics` | Routed transfer, modular depth and reconnection. |
| `0.50–0.58` | `logistics-manufacturing` | Passage contracts into nested tolerance fixtures. |
| `0.58–0.72` | `manufacturing` | Calibration, tooling and exact alignment. |
| `0.72–0.80` | `manufacturing-energy` | Calibration axis expands into supported span and conduit. |
| `0.80–0.91` | `energy` | Greatest scale, vertical load and heavy stillness. |
| `0.91–0.97` | `registration` | Carrier narrows; noise settles; film gate aligns. |
| `0.97–1.00` | `proof` | One documentary aperture and the Maradin record receive authority. |

An exact boundary belongs to the state beginning at that boundary. At `1`, the
projection remains `proof`.

For a range `[start, end]`, cumulative local progress is:

```text
rangeProgress(p, start, end) = clamp01((p - start) / (end - start))
```

The projection exposes these cumulative scalars:

- `release`, `automotive`, `automotiveToLogistics`, `routing`,
  `logisticsToManufacturing`, `tolerance`, `manufacturingToEnergy`, `load`,
  `registration` and `proof`;
- `track`, a piecewise current-position projection;
- `fieldNoise`, which declines toward registration;
- `carrierWeight`, which increases through Energy and narrows for Proof;
- bounded residue values for Automotive, Logistics and Manufacturing.

Because range scalars saturate after completion, later states can retain
earlier material without relying on an earlier scroll visit. Presence values
may reduce a completed territory to a non-zero residue, but no territory's
history is reconstructed from mutable state.

## Native-scroll controller

The controller uses the accepted lifecycle pattern without sharing or mutating
the Phase 7B controller:

```text
scroll / resize / fonts ready / restoration
  -> mark projection dirty
  -> schedule at most one RAF
  -> measure if invalidated
  -> read current document position
  -> project complete state from current progress
  -> write datasets and --territory-* properties
  -> mark settled and clear RAF handle
```

The controller queries only `[data-territory-traverse]` and guards duplicate
initialization with `data-territory-controller="ready"`. Its observable state
is:

- `data-territory-mode="enhanced|static"`;
- `data-territory-state` from the exact state table;
- `data-territory-progress` as a normalized fixed-precision value;
- `data-territory-projection="dirty|settled"`;
- namespaced `--territory-*` custom properties only.

It owns one `AbortController`, one passive `scroll` listener and at most one RAF.
`resize` invalidates chapter and rail measurements. `document.fonts.ready`
invalidates once only if the controller is still live. `visibilitychange`
cancels a pending frame while hidden and remeasures when visible. `pagehide`
cancels the frame; a non-persisted departure aborts all owned listeners and
removes the guard, while a persisted departure remains ready for `pageshow`.
A persisted `pageshow` remeasures and immediately projects the restored
position. There is no timer, interval, observer requirement, playback clock,
promise queue or transition-completion dependency.

The controller never calls `scroll`, `scrollTo`, `scrollBy`, `scrollIntoView`,
writes `scrollTop`, cancels wheel/touch movement or owns history. It has no
pointer controller. It compares the next fixed-precision projection with its
last written value and avoids redundant writes while clamped before or after
the chapter.

The accepted Phase 7B controller continues to exist independently. Phase 7C
therefore adds exactly one homepage scroll listener and one possible one-shot
RAF path; validation reports the total rather than claiming that the complete
homepage has only one listener.

## Forward, reverse and discontinuous-input models

### Forward progression

```text
accepted DECIDE
  -> accepted METHOD release / normal document breathing
  -> Phase 7C release (0.00)
  -> AUTOMOTIVE (0.10)
  -> automotive-logistics reconfiguration (0.28)
  -> LOGISTICS (0.36)
  -> logistics-manufacturing contraction (0.50)
  -> MANUFACTURING (0.58)
  -> manufacturing-energy expansion (0.72)
  -> ENERGY (0.80)
  -> REGISTRATION (0.91)
  -> MARADIN PROOF (0.97–1.00)
```

### Complete reverse

```text
MARADIN PROOF
  <- registration aperture closes into the exact evidence line
  <- ENERGY conduit and supported span
  <- Manufacturing calibration axis and fixtures
  <- Logistics routes and transfer thresholds
  <- Automotive low horizon
  <- Phase 7C release
  <- accepted DECIDE, unchanged
```

Forward and reverse call the same projection function. Direction changes no
class list, history buffer or playback state.

### Fast skip and immediate reversal

```text
scroll sample at DECIDE
  -> next delivered sample at ENERGY
  -> project ENERGY directly, including inherited residues
  -> immediate sample at LOGISTICS
  -> project LOGISTICS directly
  -> no queued Automotive/Manufacturing frames
```

Latest document position always wins. A pending RAF reads `window.scrollY` at
execution time rather than storing an obsolete progress value in the event
handler.

### Viewport resize

```text
current document position
  -> resize marks geometry invalid and projection dirty
  -> one RAF remeasures chapter, viewport and capped track travel
  -> choose enhanced or static presentation mode
  -> reproject the same current document position
  -> no scroll-position write and no state replay
```

If a resize crosses a mode boundary, CSS responds to the root dataset in the
same write. Sticky negative margin and visual display are removed in static
mode before the next paint; semantic content remains in the same DOM order.
Returning to a capable viewport remeasures the existing controller and does not
bind a second listener.

### Restoration into the middle

```text
pageshow / initial load at restored scrollY
  -> measure current chapter and rail bounds
  -> normalize restored document position
  -> project the exact territory or transition in one write
  -> expose data-territory-projection="settled"
```

Restoration into Automotive, Logistics, Manufacturing, Energy, registration or
Proof does not require an earlier territory to have executed.

## Presentation modes

### Capable desktop

The enhanced mode is eligible only above `40rem`, above `30rem` viewport
height, without reduced motion and without unsafe text zoom. It uses one bounded
sticky visual with ordinary vertical document progress. There is no horizontal
input, wheel interception, nested scroll, snap or repeated activation gesture.
The normal-flow handoff precedes it. The sticky runway ends after registration,
before the documentary Proof section; that real normal-flow record is the
post-sticky release.

Territory rhythm is intentionally unequal:

- Automotive receives the longest lateral opening;
- Logistics uses shorter routed changes and a settled transfer hold;
- Manufacturing slows into precise contraction and holds;
- Energy expands, then remains heavy and still;
- registration is quiet and exact before documentary pixels appear.

### Tablet

From `40rem` through `64rem`, a capable tall viewport may keep the bounded
sticky system with a shorter measured rail, fewer far-field layers, smaller
titles and a larger safe text zone. The carrier and all four identities remain.
The tablet implementation does not assume desktop title positions fit.

### Mobile portrait

At or below `40rem`, the sticky rail is absent. The semantic passages form one
authored vertical environment. A continuous magenta carrier runs through the
chapter and intersects one resolved decorative composition per territory.
Automotive remains wide/low within its local composition; Logistics routes
vertically through thresholds; Manufacturing contracts into nested fixtures;
Energy becomes a tall supported conduit; registration enters the real Proof
aperture. These are not bordered cards, a miniature horizontal rail or a
carousel.

### Short landscape

At or below `30rem` viewport height in landscape, including the governed
`740×360`, `800×360`, `844×390`, `896×414` and `900×480` family, the presentation
uses resolved normal-flow states. This avoids a trapped sticky field and gives
every full title and the Proof link a reachable vertical position. Content,
not a minimum scene height, determines the section height.

### Reduced motion

`prefers-reduced-motion: reduce` selects static resolved states. There is no
lateral pan, viewport-scale travel, zoom or film transport. Direct state
changes may use restrained opacity only. The carrier remains visibly continuous
through release, four territories and Proof; the image and Maradin link remain
fully available.

### No JavaScript

Static is the authored default in the HTML. Without JavaScript:

- the enhanced sticky visual is never displayed and creates no runway;
- all four real industry headings and statements appear in order;
- each territory exposes its resolved static spatial composition;
- one continuous vertical carrier retains identity;
- the Maradin figure, title and direct anchor remain available;
- no video source or decoder exists and no interaction is required to reveal
  meaning.

### Genuine browser-native 200%

The controller applies the accepted text-zoom safety signals: root font size,
`visualViewport.scale` and the installed-desktop-Chrome outer/inner-width ratio.
At genuine 200%, unsafe sticky geometry yields to the same complete static
presentation. This is not CSS zoom, a transform or viewport emulation. All
titles, especially `MANUFACTURING`, remain whole; the Proof link and Field Map
remain keyboard usable; horizontal overflow remains zero.

## Failure and fallback handling

- **Controller unavailable or throws before enhancement:** the authored
  `data-territory-mode="static"` DOM remains complete. No watchdog or delayed
  recovery is necessary.
- **Fonts not ready:** enhancement may initialize, but settled-state evidence
  waits for font readiness; the font-ready callback performs one guarded
  remeasure. Fallback-font geometry is independently authored and tested.
- **Document hidden:** a pending RAF is cancelled. Nothing progresses while
  hidden. Visible restoration resamples current document position.
- **Non-persisted departure:** all Phase 7C listeners are aborted and the guard
  removed. There is no media resource to release.
- **Persisted restoration:** the existing controller resamples on `pageshow`;
  it does not bind again.
- **Image failure/offline:** the film-gate frame, semantic caption, record copy
  and link remain. There is no retry loop.
- **Fast scroll:** intermediate transformations may be skipped. The current
  position is projected directly and no transition is awaited.
- **Reduced motion, short viewport, mobile or unsafe text zoom:** the static
  authored sequence is the intended result, not a degraded error state.

## Validation and evidence predicates

Evidence tooling waits for observable state rather than arbitrary sleeps. A
settled enhanced territory capture requires:

- `data-territory-projection="settled"`;
- the expected exact `data-territory-state`;
- fixed-precision progress and track translation matching the current
  projection;
- the controller's RAF handle clear;
- `document.fonts.status === "loaded"` where supported;
- zero horizontal overflow;
- visible, measurable expected semantic content.

A settled Proof capture additionally requires the documentary image to be
decoded (`complete`, positive `naturalWidth`) or an explicitly recorded image
failure with the semantic fallback and link intact. Settlement latency and the
bounded timeout are recorded per case.

Validation must include exact state-boundary tests, idempotence, direct jumps,
reverse symmetry, fast reversal, resize mode changes, restoration into every
macro state, Chromium, Firefox, WebKit proxy, the complete responsive matrix,
keyboard/focus, axe, target sizes, fallback fonts, reduced motion, no JavaScript,

geometry and governed-region comparison. Neutral typography-edge differences
