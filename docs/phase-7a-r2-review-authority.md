## Bounded R2 repair

The only production repair is the Field Map disclosure's ARIA accuracy and
deterministic keyboard containment. The Field Map remains native
`details`/`summary` navigation with one summary and eight ordinary links.
It does not become a menu, menubar, listbox, tree, grid, dialog or application.

The repair removes the inaccurate popup assertion, retains the unique useful
`aria-controls` relationship, uses native disclosure state, and establishes a
documented nine-control focus order. Enhanced opening moves focus directly to
the current or first destination; Tab and Shift+Tab advance exactly one item
and wrap; Escape closes and returns focus; a bounded open-state `focusin`
safeguard recaptures unexpected escape; and owned containment is removed on
close, navigation and lifecycle cleanup. Native no-JavaScript behavior remains
available.
