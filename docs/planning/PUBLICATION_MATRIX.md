## Deny-by-default publication rules

1. A public asset requires classification A or an explicitly approved B record plus a matching asset-register hash.
2. A public content record requires explicit field-level approval; an approved asset does not authorize adjacent claims.
3. Unknown or unverified fields are omitted, not inferred.
4. Internal source references and approval packets are not serialized into generated output.
5. No Q-HUB runtime code, visual system or controller crosses the source boundary.
6. A prohibited-output scan covers generated HTML, CSS, JavaScript, JSON, metadata and public filenames.
7. A failure blocks the Phase 0 handoff; it is not waived by a successful build or preview deployment.
