The strongest route theses for For industry, For startups, Industries, SPARK,
About, Contact, and 404 are authored spatial/material systems and do not need real
photography. Proof and Maradin already have sufficient governed media. Therefore:

- connected Google Drive review is not required for Phase 5A;

- any request to add later real media is a separate human approval with a named
  route, role, rights basis, publication classification, and fallback.
