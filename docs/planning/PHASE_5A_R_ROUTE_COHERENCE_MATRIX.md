## Shared laws that do not create a shared template

- Exactly one semantic H1 per route study.
- No sticky chapters, scroll locking, cinematic replay, frame sequence, autoplay, continuous loop, or third-party runtime.
- Reduced motion and no JavaScript preserve the complete reading order.
- Magenta is an activation edge only, never a universal seam.
- Metadata is integrated only where it is part of the route thesis: documentary captions for Maradin, a record marker for Proof, and no repeated three-column strip.
- Endings are route-specific; silence and direct recovery are allowed.
- Human visual judgment remains the authority. This matrix is evidence for the pending route-identity gate, not an acceptance decision.
