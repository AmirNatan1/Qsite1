## Purpose

The reference supplies an experience-quality benchmark only. Quantum may retain principles such as spatial escalation, scroll-owned camera-to-interface continuity, and a visually matched DOM handoff. It must produce an original subject, composition, physical mechanism, timing, object language, camera choreography, interface, responsive treatment, and content system.

No reference screenshot or binary asset is included in this repository. Creative review uses written observations and original Quantum evidence.

## Spiral Conduction originality tests

The Phase 0 creative package passes only when all are true:

1. The physical cable is clearly one continuous grounded object.
2. Its inner terminus visibly reaches a credible Field Unit port.
3. Its outer terminus reads as the current's origin.
4. The selected spiral uses approximately 2.25-2.75 turns with deliberate spacing and no decorative second wire.
5. Progress `0.00` contains no visible magenta environmental light.
6. A single cumulative current front advances outside-in.
7. The cable ahead is dormant and the cable behind remains illuminated.
8. Current does not leave the cable and no particle, ball, pulse train, arc, or beacon substitutes for conduction.
9. The camera changes angle while conduction advances but reaches near-frontal alignment before the current enters the unit.
10. The Field Unit remains off until the connector event.
11. Power-on is restrained and sequential; it does not illuminate every seam.
12. The portal reads as a Q-derived industrial interface, not a laptop, glowing circle, wormhole, or operating-system screen.
13. The final visual frame and first DOM frame align without a blank bridge.
14. Reverse behavior is the exact state inverse of forward progress.
15. Mobile is independently composed, and reduced motion shows the dormant state with no simulated movement.

## Prohibited source and artifact use

- traced reference geometry or an unmistakably matching frame sequence;
- scraped or stock product models standing in for the Field Unit;
- generic laptop or science-fiction device stock;
- another company's product render;
- fabricated Quantum photograph, employee, facility, partner, result, or testimonial;
- Q-HUB interface code, visual grammar, controllers, route layouts, or later unaccepted assets.

## Human originality gate

Technical test success does not prove originality. Before full cinematic integration, a human reviewer must choose:

```text
FIELD UNIT + SPIRAL CONDUCTION + PORTAL CREATIVE:
ACCEPT / REPAIR / 2.5D REDIRECT
```

`REPAIR` requires a new evidence set and comparison. `2.5D REDIRECT` authorizes the original browser-native premium 2.5D direction as the production medium; it does not weaken any originality rule.
