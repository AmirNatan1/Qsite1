# Phase 7A retention and demolition map

This map was completed before any production code was deleted or replaced. Its
purpose is to remove the rejected post-CRT experience without weakening the
accepted physical opening, publication truth, semantics, accessibility, or
runtime lifecycle.

## Classification rules

- **KEEP UNCHANGED** — byte-preserved on the Phase 7A branch.
- **KEEP AND EXTRACT FOUNDATION** — retain the verified nonvisual contract while
  moving its presentation to the Phase 7A architecture.
- **REPLACE** — remove the existing visible behavior and author a new Signal
  Field implementation in the same or named successor file.
- **DELETE** — remove from the active branch; Git history is the archive.
- **TEMPORARY SEMANTIC SHELL** — retain complete approved semantics and route
  behavior in an intentionally neutral Phase 7A presentation.
- **REVIEW REQUIRED** — preserve until evidence proves removal is safe.

## New Phase 7A production surface

The bounded successor is limited to:

- `SignalThreshold.astro`: CRT-derived digital breach, exact Q, live semantic
  manifesto and persistent structural field;
- `phase-7a-signal-field.css`: CSS/SVG/DOM substrate and authored responsive,
  reduced-motion, no-JS and fallback-font states;
- a small dependency-free probe controller: pointer input marks dirty, one RAF
  writes local pressure, and work stops; touch receives a static/document-authored
  composition;
- a semantic Field Map in `SiteHeader.astro` using ordinary links and a native
  no-JS disclosure;
- `phase-7a-semantic-shell.css` plus rewritten supporting-route components;
- Phase 7A typography, architecture, mechanics and validation documentation.

No React, Three.js, animation framework, scene graph, physics library, Canvas or
shader dependency is planned. CSS, SVG and semantic DOM are sufficient for the
prototype requirement.
